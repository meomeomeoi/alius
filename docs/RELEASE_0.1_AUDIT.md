## C. Can wait (minor or defence in depth)

- **Security:** `readDayStart` (`src/st/persistence.ts:19-25`) skips `migrate` before a LEASHSWAP rewind swaps it in; no error boundary around `reload`/`afterLoad`/tab render (a broken save can leave SYS unreachable in that chat; mark read-only instead); `wardenPanel.ts:56` builds `width:${w.defiance}%` from state (CSS injection → remote beacon; clamp the number); pass `{ escapeHtml: true }` to toastr explicitly; `stripThinking` quadratic on many unclosed `<think>` (bounded by max_tokens).
- **Integration:** P7 "commander file incomplete" review never shows (opened while the shell is closed, `reviewShownFor` set anyway; only pre-P7 saves); `overrideModalOpen` not reset on chat switch (LEASHSWAP); `reload()` disposes instead of flushing the saver (≤ 500 ms of changes lost on switch); combat hotkeys act behind open modals (`ui/combat/keys.ts:24-45`, check `.alius-modal-backdrop` like the hub); `message_deleted` may pass the new chat length instead of an index (check ST); one synchronous throw in `followUps` skips the rest; `envelope.run` does not catch a throwing `build`/`parse`.
- **Engine (plausible):** vote spent when the gated action returns events but did not run (desertion at mission start, warden override); `averageLevel` (`combat/encounter.ts:20`) counts dead units; habit XP may wait for the next level-up depending on hook order.
- **Content consistency:** US/UK spelling mixed (armor/defense/color vs colour/favour/judgement — pick one); Plyx/plyx/PLYX; "the Leash" vs "holds the leash"; button padding `[CANCEL]` vs `[ CANCEL ]` (and SAVE, BACK, ACCEPT, RETREAT, …); dilemma options in mixed case; terse role branch summaries ("Crit.", "Heals."); `expeditionScreen.ts:154` "someone must cover the commander" → "someone must provide cover"; Kestrel "more metal than flesh" contradicts the 2026-11-19 "biopunk, not chrome" note.
- **Balance:** known, in `BALANCE_REPORT.md` (danger 4: six defects +5.7…+13.6 pp).
- **Lore** is still marked placeholder (`docs/content/lore.md`): the author's call whether 0.1 ships with it.

## Checked and clean

- **Security:** no `innerHTML`/`eval`/`new Function`/string timers; all DOM via text nodes (`h()`); `assetUrl` stays same-origin; no `url(` with a scheme; content loader merge guards `__proto__`; every model JSON zod-validated and sanitized (ids against present units/registries, clamps); slash escaping (`slashArg`) has no known bypass besides A1; ST writes scoped (lorebook only if absent, open group only, chat-bound saver, read-only never overwritten); runtime dependency zod 3.25.76 only.

- **Integration:** envelope (chat check after each await, RETRY/REROLL guards), orchestrator timeout/abort and fallback to main without Connection Manager, every async dispatch carries `expectChatId`, injections cleared for non-campaign and read-only chats, shell modal/Escape/Tab, locked tabs, hub/scene teardown.

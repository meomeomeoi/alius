# Recorded sounds

The instruments' recorded sounds (P10e chunk (e)), copied from `docs/prototypes/assets/` (whose `LICENSES.md` is the source of these rows); only the files a prototype's normative section names. Each file is named here.

## `breath-in-out.mp3`

- `breath-in-out.mp3` — "in-out-breath", freesound.org sound 813664 by `sounds_fab`, CC0 (licence as given by the author when adding it, 2026-11-23). One nose inhale (0.12–1.44 s) and one exhale (2.17–3.23 s). Used by breath, saturation, the slap, the jaw, the frame (her activity), the throne and gulp.
